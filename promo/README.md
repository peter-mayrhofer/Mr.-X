# Promo-Material

Aus einem simulierten Spiel mit der echten App aufgenommen.

| Datei | Inhalt |
|---|---|
| `Mister-X-Rote-Falken.mp4` | Langes Video (1:54, Querformat 1920×1080) – Admin, Mister X, Jäger, Schiri, Fang aus drei Sichten, Zeitraffer, Siegerehrung, Archiv |
| `Mister-X-Rote-Falken-Kurz-Hochformat.mp4` | Kurzfassung (41 s, Hochformat 1080×1920) für WhatsApp-Status, Instagram-Story/Reel |
| `Mister-X-Promo-Hype.mp4` | Hype-Clip (16 s, Querformat 1920×1080, 60 fps): Funke → MISTER X → Jagen/Fangen/Mister X werden → Live-Karte → Übergabe in der App → Logo |

| `hype/SOUND.md`, `hype/CREDITS.txt`, `hype/beatgrid.png` | Ton-Protokoll (Lautheit, Beat-Abgleich), Quellen von Musik und Soundeffekten, Beat-Kontrolle (Bassdrum gegen Beat-Linien) |

| `Mister-X-Rundgang-Hochformat.mp4` | Derselbe Rundgang im Hochformat (1080×1920) für Reels, Stories und WhatsApp-Status |
| `Mister-X-Unslop.mp4` | Vorher-Nachher (9 s, quadratisch 1080×1080, 60 fps): die Siegerehrung am Beamer räumt sich auf – Deko weg, Etiketten normal geschrieben, ruhige Kennzahlen, zweispaltig und groß.
